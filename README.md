# Campus Navigation (Universal AI University, Karjat)

Campus navigation feature for the college app: search a place and get the shortest walking route from the main gate
(or a QR code / GPS start), outdoors on a map and indoors on the floor pictures, across the ground, first and second
floors of the main building.

**Stack:** A* routing, Flask REST API, Flutter UI (separate repo `UAI-FOUNDRY/CampusNav-Flutter`), GeoJSON + floor-plan data.

## Folders
- `data/outdoor/`  outdoor paths and doors drawn in geojson.io (`outdoor_draft_vN.geojson`, newest wins)
- `data/indoor/`   one file per floor (`gf.json`, `ff.json`, `sf.json`) + `building.json` (GPS tie-in, lifts, stairs)
- `data/places.json`  what students can search for
- `data/build/campus.merged.json`  generated by `tools/merge_data.py` (commit it; the server reads only this)
- `tools/`         merge, check and drawing tools; `node_editor/` for indoor dots
- `backend/`       Flask API and A* routing
- `app/assets/floorplans/`  the public signage pictures the app shows (ground.png, first.png, second.png)
- `private/`       the architect's floor plans and anything made from them. **Git-ignored: never commit or share.**
- `docs/`          data format, mapping guide, API, edge cases, live tracking, street view, indoor survey checklist

## Everyday commands (Windows PowerShell, from this folder)
```
.venv\Scripts\Activate.ps1
python tools/check_map.py            # outdoor drawing mistakes (must be 0 problems)
python tools/merge_data.py           # build data/build/campus.merged.json
python tools/check_routes.py --all   # gate -> every place, finds unreachable ones
cd backend ; python -m pytest ; cd ..
cd backend ; python -m flask --app wsgi run --host 0.0.0.0
```
See `docs/mapping-guide.md` for how to change the map and `docs/api.md` for the endpoints.
